# DATA_SOURCES.md - Data Source Matrix

This document tracks all external weather, mapping, and sensor APIs used by Salvus.

---

## 1. Live vs. Simulated Mapping

| Data Source | Status | Access Method | Purpose | Fallback / Limitation |
| :--- | :--- | :--- | :--- | :--- |
| **Open-Meteo Weather API** | Live | HTTP GET | Pulls temperature, rain, and wind metrics. | Fallback to hardcoded historical weather grid if rate-limited. |
| **GDACS Disaster Alerts** | Live | RSS / HTTP JSON | Pulls global floods and tropical storms. | Fallback to USGS global earthquake feed. |
| **USGS Earthquake Feed** | Live | HTTP GeoJSON | Fetch active seismic occurrences. | Render last-cached earthquake map pins. |
| **OpenStreetMap Tiles** | Live | HTTP Raster Tiles | Base layer raster maps for leafmap widget. | Hardcoded fallback base raster server. |
| **Nominatim Geocoding** | Live | HTTP GET queries | Converts user coordinates to address fields. | Fallback to rendering raw coordinates (lat/lng). |
| **OSRM Routing Engine** | Live | HTTP API | Calculates travel distances, routes, and ETAs. | Fallback to straight-line Euclidean distance calculations. |
| **Citizen Reports** | Live | HTTP Post / Socket | Dynamic emergency entries generated by portal users. | Store locally in client state if server is offline. |
| **Responder GPS** | Simulated | Internal Seed Timer | Simulated responder GPS movements along OSRM paths. | Clearly labeled with `[SIMULATION]` in the UI. |
| **Flood Sensors** | Simulated | Seed Data Generator | Mocked sensor inputs for rising river levels. | Clearly labeled with `[SIMULATION]` in the UI. |

---

## 2. API Specifications & Integration Gaps
* **Rate Limits:** Nominatim allows 1 request/second. Salvus caches results in the database using coordinates to minimize duplicate requests.
* **Geospatial Limits:** OSRM routes are computed over public roads. If coordinates fall outside searchable grids, route matching falls back to direct line calculation.
